## 四、踩坑记录（AI 也会错，例子）

1. AI 起草的 node-exporter 用 host 网络+127.0.0.1 监听 → 容器网 Prometheus 够不着，改为桥接网不发布端口
2. AI 起草的 alertmanager.yml 写了 `cluster:` 配置块 → 0.27 配置 schema 不认，改为命令行 flag
3. AI 起草的备份脚本把 age 密钥生成 delegate_to 本机 → Windows 本机无 age；且密钥应留在服务器（私钥出服务器=备份可被他人解密）
4. compose build 相对路径基准是 compose 文件目录而非运行目录 → 起动即报 path not found
5. git-bash curl 发中文 JSON 会因 GBK 编码报 "error parsing the body"（工具假象）→ 测中文请求体一律用 httpx（E2E 脚本即如此）
6. Pydantic 422 默认吐英文结构体数组，前端直接渲染=天书 → main.py 注册 RequestValidationError handler 翻译成中文逐字段提示（面试可讲：错误信息也是产品的一部分）
